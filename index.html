A Web deve ser para todas as pessoas.

O que é Acessibilidade Web (a11y)?

Acessibilidade Web significa garantir que pessoas com deficiência possam compreender, navegar, interagir e contribuir para a Web. Ela beneficia também pessoas com limitações temporárias ou de idade avançada.
